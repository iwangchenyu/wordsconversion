# 在线简繁体字转换

> 简体中文与繁体中文互相转换的纯前端工具。

在线体验：https://wangchenyu.com/gongju/wordsconversion/

## 功能特性

- 简体 → 繁体
- 繁体 → 简体
- 结果一键复制

## 使用方法

1. 用浏览器直接打开 `index.html`，无需安装任何软件、无需构建、无需后端服务。
2. 所有计算与处理均在浏览器本地完成，数据不会上传到服务器。
3. 处理完成后使用页面上的复制 / 导出按钮即可保存结果。

## 技术栈

原生 JavaScript 简繁字库

## 目录结构

```
├── index.html        # 主页面
├── assets/ 或本地资源 # 样式、脚本与静态资源（按需）
```
